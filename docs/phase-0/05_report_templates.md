## 4. CSV Formula-Injection Mitigation Protocol

When exporting any tabular report to CSV:
1. Test each text field value.
2. If the field starts with any of the dangerous spreadsheet formula triggers: `=`, `+`, `-`, `@`, `\t`, `\r`:
   - Prepend an apostrophe (`'`) or quote the cell safely.
3. Wrap all strings containing commas or quotes in standard RFC 4180 quotation marks.
4. Set response headers:
   - `Content-Type: text/csv; charset=utf-8`
   - `Content-Disposition: attachment; filename="iti_attendance_batch_el2026a_oct2026.csv"`
   - `X-Content-Type-Options: nosniff`
